# claude-work

A small collection of simple, usefull utility functions for basic arithmetic operations.

## Usage

```python
from calculator import add, subtract, multiply, divide

add(2, 3)       # 5
subtract(5, 3)  # 2
multiply(4, 3)  # 12
divide(10, 2)   # 5.0
```

## Running tests

```bash
pip install pytest
pytest
```
