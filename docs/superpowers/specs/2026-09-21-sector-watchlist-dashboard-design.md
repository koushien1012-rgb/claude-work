# セクター・ウォッチリストボード 設計書

- 日付: 2026-09-21
- 対象: `stock-data-tool` に新設する「セクター・ウォッチリストボード」（固定30銘柄の定点観測ダッシュボード）

## 背景・目的

ユーザーが興味を持つ4セクター（宇宙・防衛・船舶・メモリ半導体）について、日米の代表銘柄を洗い出し（各セクター日米4銘柄ずつ、重複除く実質30ユニーク銘柄）、既存の`generate_report()`パイプラインで一度テクニカル・ファンダメンタルズ分析を行った。これを一過性のチャット出力で終わらせず、相場ボードと同じ見た目・使い勝手の専用ダッシュボードとして常設し、毎日自動更新したい、という要望に基づく。

投資助言は行わない（既存の相場ボード群と同じ立ち位置：機械的なテクニカルスコアとファンダメンタルズ材料の提示のみ）。

## スコープ

- 含む: 固定30銘柄の日次データ取得・スコアリング・ダッシュボード表示、moomoo証券へのチャートリンク、Claude Codeのスケジュールタスクによる日次自動実行
- 含まない: Claude APIによる個別銘柄への定性的判断コメント生成（追加API課金が発生するため今回は見送り。将来的なオプションとして設計上は排除しない）
- 含まない: 動的スクリーニング（相場ボードのような700銘柄からの自動選定）。銘柄リストは固定

|---|---|---|

## アーキテクチャ

### 1. `generate_sector_watchlist.py`（新規、リポジトリ直下）

`generate_daily_watchlist.py`と同じ構造・依存関係を踏襲する:

- 上記の固定ティッカーリスト（セクター・市場のマッピング込み）をモジュール定数として保持
- 各ユニークティッカーに対して`analysis.generate_report(ticker, name=..., sector=...)`を呼び出す（新規のスコアリングロジックは不要、既存のダウ理論・ワイコフ・ローソク足・フィボナッチ・ボリュームプロファイル・短中長期スコアをそのまま利用）
- 銘柄が複数セクターに属する場合（三菱重工業・IHI）は、レポート取得は1回のみ行い、出力側で所属セクターを配列として保持する
- 追加のClaude API呼び出しは行わない（`claude_judgment`相当のフィールドは持たない）
- 出力は`output/watchlist/sector_watchlist_data.json`ではなく、**`dashboard/sector_watchlist_data.json`に直接書き出す**（相場ボード等の「手動コピー」運用とは異なり、スケジュールタスクからの完全自動実行に対応するため）
- 例外処理：個別銘柄のレポート取得に失敗しても、その銘柄をスキップして処理を継続する（`generate_daily_watchlist.py`の`_build_market_block()`と同じ方針）

### 2. `dashboard/sector-watchlist.html`（新規）

相場ボード（`dashboard/index.html`）と同じCSS変数・フォント・コンポーネント（`.gauge`、`.sparkline`、`.insight-line`、`chartUrl()`によるmoomooリンク等）を再利用し、以下の構成で表示する:

- ヘッダー：更新日時、走査銘柄数
- 4セクターのセクションを縦に並べ、各セクション内で「米国株」「日本株」を左右2カラム（相場ボードの`.boards`グリッドと同じレイアウト）で表示
- 各銘柄行：ティッカー・企業名・現在値・短中長期ゲージ・moomooチャートリンク。展開すると、ダウ理論・ワイコフ・ローソク足パターンの内訳、見立て文（相場ボードの`insightLine()`をそのまま再利用）、ファンダメンタルズ材料の見出しを表示
- 重複銘柄（三菱重工業・IHI）は該当する全セクションに表示する（同一データを参照）

### 3. 日次自動実行

Claude Codeのスケジュールタスク機能（`mcp__scheduled-tasks__create_scheduled_task`相当）で、毎日1回（具体的な時刻は実装時にユーザーへ確認し、cron式で設定する）以下を実行する:

1. `python generate_sector_watchlist.py`を`stock-data-tool/`ディレクトリで実行
2. 終了コード・出力銘柄数を確認し、異常があれば通知
3. 正常終了時は特に追加アクションなし（ダッシュボードは次回アクセス時に最新データを表示）

## 検証方法

- 実データで`generate_sector_watchlist.py`を1回実行し、30銘柄すべてが取得できること、`dashboard/sector_watchlist_data.json`が正しいスキーマで書き出されることを確認する
- ダッシュボードをローカルで開き、4セクション×日米の表示、ゲージアニメーション、moomooチャートリンク、見立て文が正しく描画されることをブラウザで確認する
- スケジュールタスクを作成し、初回実行が成功することを確認する

## 既知の制約

- 銘柄リストは固定のため、将来的にセクターや銘柄を追加・変更したい場合はスクリプトの定数を手動で編集する必要がある
- Claude Codeのスケジュールタスクは、Claude Codeアプリ／セッション基盤が利用可能である前提で動作する（PCの電源が切れている場合等は実行されない可能性がある）
